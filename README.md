# 뽀짝이: 개인 일정 정리 비서

## 이 비서가 해결할 생활 문제

메모나 자연어로 적어 둔 개인 일정과 업무 일정을 오늘과 이번 주 기준으로 다시 보기 쉽게 정리합니다. 일정이 빠지지 않았는지 확인하는 데 도움을 주지만, 캘린더를 직접 바꾸거나 알림을 보내지는 않습니다.

## 이번 주의 작은 성공 기준

일주일 동안 메모 3개 이상을 넣어 보고, 뽀짝이가 다음 세 가지를 제대로 해내면 성공입니다.

1. 오늘 일정과 이번 주 일정을 구분한다.
2. 시간순으로 짧게 정리한다.
3. 날짜나 시간이 애매한 항목을 `확인 필요`로 남긴다.

## 예상 입력과 결과

입력 예시:

```text
내일 오전 10시 팀 회의
금요일까지 보고서 초안 보내기
다음 주 화요일 치과, 시간은 아직 모름
```

결과 예시:

```text
오늘 일정
- 없음

이번 주 일정
- 내일 10:00 팀 회의
- 금요일까지 보고서 초안 보내기

확인 필요
- 다음 주 화요일 치과: 시간이 정해지지 않음
```

## 현재 구현 상태와 다음 행동

현재는 아이디어와 안전 기준을 정리한 첫 작업공간입니다. 실제 자동 분류, 캘린더 연결, 알림 발송은 아직 구현되지 않았습니다.

이번 주 첫 테스트:

1. 최근 메모에서 민감한 정보를 지운 일정 3개를 준비합니다.
2. 일정 메모를 뽀짝이에게 한 번에 붙여 넣습니다.
3. 오늘·이번 주 요약을 확인합니다.
4. 틀리거나 빠진 내용을 사람이 고칩니다.

## 폴더 사용법

- `assistant-soul.md`: 뽀짝이의 역할과 말투를 설명합니다.
- `idea-seed.md`: 첫 기능의 범위와 테스트 방법을 설명합니다.
- `privacy-boundaries.md`: 입력 전에 지울 정보와 권한 경계를 설명합니다.
- `.gitignore`: 개인 원본이나 인증 파일이 Git에 들어가지 않게 합니다.
